第 2 步：安装并信任

iPhone / iPad
  1. 用 Safari 点上面的下载按钮，选择「允许」。
  2. 打开「设置」，顶部会出现「已下载描述文件」，点进去 → 安装。
  3. 再到「设置 → 通用 → 关于本机 → 证书信任设置」，打开 HeyFiles Local CA 的开关。
Android
  1. 点下载按钮，保存证书文件。
  2. 「设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书」（不同品牌位置略有差异，可在设置里搜索“CA 证书”）。
  3. 选择刚下载的 HeyFiles-CA.crt。
Windows 10 / 11（Chrome、Edge）

Chrome 和 Edge 用的是 Windows 系统证书库，装一次两个浏览器都生效。括号里是英文版 Windows 的按钮名称。

方法一：图形界面

  1. 点上面的「下载 HeyFiles 证书」。如果浏览器提示文件可能有害，选「保留」（Keep）。
  2. 在下载列表或「下载」文件夹里双击 HeyFiles-CA.crt。如果弹出“打开文件 - 安全警告”，点「打开」（Open）。
  3. 在证书窗口里点「安装证书…」（Install Certificate…）。
  4. 存储位置选「当前用户」（Current User），点「下一步」（Next）。
    选「本地计算机」（Local Machine）对这台电脑的所有用户生效，但需要管理员权限。
  5. ⚠ 到“证书存储”（Certificate Store）这一步，不要用默认的“自动选择”（Automatically select…）。默认会把证书放进“中间证书颁发机构”，浏览器还是不会信任。
  6. 选「将所有的证书都放入下列存储」（Place all certificates in the following store）→ 点「浏览…」（Browse…）→ 选「受信任的根证书颁发机构」（Trusted Root Certification Authorities）→「确定」（OK）。
  7. 点「下一步」（Next）→「完成」（Finish）。
  8. 会弹出“安全警告”（Security Warning），问是否安装 HeyFiles Local CA。先核对里面的指纹 (sha1)（Thumbprint (sha1)）是否和下面这串一致，一致再点「是」（Yes）：
    {{.Thumbprint}}
  9. 看到“导入成功”（The import was successful）就装好了。

方法二：一条命令（适合熟悉命令行的用户）

下载证书后，打开“命令提示符”或 PowerShell（不需要管理员），运行：

certutil -user -addstore Root "%USERPROFILE%\Downloads\HeyFiles-CA.crt"

PowerShell 里把 %USERPROFILE% 换成 $env:USERPROFILE。同样会弹出安全警告，核对指纹后点「是」。

装好之后

  1. 彻底关闭浏览器：关掉所有窗口，并检查右下角托盘里有没有 Chrome / Edge 图标还在后台运行，有就右键退出。
  2. 重新打开浏览器，访问本页。显示“已信任”后会自动跳转到 HTTPS，地址栏出现小锁、没有“不安全”（Not secure）就成功了。

还是提示“不安全”？

  1. 按 Win + R，输入 certmgr.msc 回车。
  2. 看「受信任的根证书颁发机构 → 证书」（Trusted Root Certification Authorities → Certificates）里有没有 HeyFiles Local CA。
  3. 没有的话，多半是装到了「中间证书颁发机构」（Intermediate Certification Authorities）。在那里删掉它，再按上面的步骤重新安装。
  4. 装好后一定要彻底重启浏览器。

Firefox

Firefox 默认用自己的证书库：设置 → 隐私与安全 → 证书 →「查看证书」→「证书颁发机构」→「导入」，选 HeyFiles-CA.crt，勾选「信任由此证书颁发机构来标识网站」。

以后想删除

打开 certmgr.msc →「受信任的根证书颁发机构 → 证书」→ 右键 HeyFiles Local CA →「删除」。

macOS
  1. 双击下载的证书，添加到「登录」钥匙串。
  2. 在「钥匙串访问」里双击 HeyFiles Local CA → 信任 →「使用此证书时」选「始终信任」。
Linux
  1. Chrome / Chromium：设置 → 隐私和安全 → 安全 → 管理证书 → 授权机构 → 导入。
  2. Firefox：设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入。
